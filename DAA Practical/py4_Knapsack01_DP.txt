"""
QUESTION 4 (DAA):
Write a program to solve a 0-1 Knapsack problem using dynamic programming
(or branch and bound strategy).

HOW IT WORKS
    dp[i][w] = best value using only the first i items with capacity w.

    For every item and capacity:
        skip item i : dp[i][w] = dp[i-1][w]
        take item i : dp[i][w] = value[i] + dp[i-1][w - weight[i]]
        dp[i][w]     = max(skip, take)   (take only if weight[i] <= w)

    dp[n][capacity] is the answer. To find which items were chosen, walk the
    table backwards: if dp[i][w] differs from dp[i-1][w], item i was taken.

STEPS
    1. Imports
    2. Input items and capacity
    3. Build the DP table
    4. Trace back the chosen items
    5. Run and print the result
    6. Inspect the DP table
    7. Observation

RUN
    python3 daa/py4_Knapsack01_DP.py

    In Jupyter, open py4_Knapsack01_DP.ipynb or split this file at the
    "# %%" markers.
"""

# %% Step 1: Imports
from collections import namedtuple

# %% Step 2: Input items and capacity
# Items and capacity are now read from the user at run time.
Item = namedtuple("Item", ["index", "value", "weight"])

n = int(input("Enter number of items: "))
items = []
for i in range(1, n + 1):
    value = int(input(f"Enter value of item {i}: "))
    weight = int(input(f"Enter weight of item {i}: "))
    items.append(Item(i, value, weight))
capacity = int(input("Enter knapsack capacity: "))

for item in items:
    print(f"Item {item.index}: value={item.value}, weight={item.weight}")
print("Capacity:", capacity)

# %% Step 3: Build the DP table
def knapsack_dp(items, capacity):
    """Fill the DP table; return (dp table, maximum value)."""
    dp = [[0] * (capacity + 1) for _ in range(len(items) + 1)]

    for i, item in enumerate(items, start=1):
        for w in range(capacity + 1):
            if item.weight <= w:
                take = item.value + dp[i - 1][w - item.weight]
                skip = dp[i - 1][w]
                dp[i][w] = max(take, skip)
            else:
                dp[i][w] = dp[i - 1][w]
    return dp, dp[len(items)][capacity]

# %% Step 4: Trace back the chosen items
def selected_items(items, dp, capacity):
    """Walk the table backwards and collect the item indices chosen."""
    chosen, w = [], capacity
    for i in range(len(items), 0, -1):
        if dp[i][w] != dp[i - 1][w]:
            chosen.append(items[i - 1])
            w -= items[i - 1].weight
    return chosen

# %% Step 5: Run and print the result
dp, best = knapsack_dp(items, capacity)

print(f"\nMaximum value = {best}")
print("Selected items:")
for item in selected_items(items, dp, capacity):
    print(f"  Item {item.index} (value={item.value}, weight={item.weight})")

# %% Step 6: Inspect the DP table
# Rows are items (row 0 = no items), columns are capacities from 0 to 50.
print("\nDP table (rows = items, columns = capacity):")
for row in dp:
    print(row)

# %% Step 7: Observation
print("\nObservation")
print("  Each cell stores the best value for that item prefix and capacity.")
print("  The final cell is the answer, and the trace-back finds the items.")




/*
Oral explanation:

"My fourth practical is the 0/1 Knapsack Problem using Dynamic Programming.

Similar to Fractional Knapsack, we are given items with weights and profits, along with a fixed knapsack capacity.

But the main difference is that in 0/1 Knapsack, we cannot divide an item. We can either take the complete item or leave it.

To solve this problem, we use Dynamic Programming.

We create a two-dimensional DP table where rows represent items and columns represent different knapsack capacities.

For every item, we have two choices:

First, exclude the item, which means we keep the previous maximum profit.

Second, include the item, if its weight is less than or equal to the current capacity. In that case, we add its profit to the best possible profit for the remaining capacity.

We select the maximum value between these two choices.

The recurrence relation is:
\[
DP[i][w] = \max(DP[i-1][w],\ value_i + DP[i-1][w-weight_i])
\]

If the item cannot fit, we simply exclude it.

After filling the table, we can also trace it backwards to identify which items were selected.

The time and space complexity are both O(nW), where n is the number of items and W is the knapsack capacity."

Remember:
- Algorithm: Dynamic Programming
- Two choices: Include or Exclude
- Items cannot be divided.
- Uses a 2D DP table.
- Time complexity: O(nW).
- Fractional Knapsack and 0/1 Knapsack are different.
